# 汐風GP（汐風グランプリ）

ブラウザで遊べる3Dカートレース。夕暮れの海辺・夜の参道・海の底の3コースを8台で3周します。

**遊ぶ:** https://nazo-sakasu.github.io/shiokaze-gp/

## オンライン対戦（サインイン不要）

1. 「みんなで」タブ → なまえを入れて **部屋をつくる**（「鍵をかける」オンなら4けたの部屋番号と鍵ができます）
2. 「招待」ボタンでリンクを送る（または部屋番号と鍵を伝える）
3. ホスト（王冠マーク）がコースとクラスを決めて「みんなでスタート」

- 最大8人。空いた枠はCPUが走ります（ホストがオフにもできます）
- 通信はプレイヤー同士の直接接続（WebRTC / PeerJS）。専用サーバーはありません
- ホストが抜けても、次に入った人がホストを引き継いでレースは続きます
- 回線の組み合わせによってはつながらないことがあります（会社のWi-Fiなど）。そのときはWi-Fiとモバイル回線を切り替えてみてください

## 操作

| キー | 動作 |
|---|---|
| ↑ / W | アクセル |
| ← → | ハンドル |
| Space | ドリフト |
| E / X | アイテム |
| ↓ | ブレーキ |
| Esc | ポーズ／メニュー |

スマホはタッチ操作に対応しています。
